- File names: `tnh-YYYY-MM-DD-<slug>.md` for talks, `tnh-book-<slug>.md` for books.
- Each text starts with a header giving source URLs, how it was obtained, the retrieval date, whether it is auto-generated or edited, and a copyright note.
